# Chris' Ice Cream & Mexican Food — Online Menu

A reference-only online menu for Chris' Ice Cream & Mexican Food in Nora Corners, Indianapolis.

- **Address:** 1484 East 86th St, Nora Corners Shopping Center, Indianapolis, IN 46240
- **Phone (orders):** (317) 255-2156
- **Hours:** 10:30am – 8:00pm, closed Sundays
- **Instagram:** [@ChrisIceCreamIndy](https://instagram.com/ChrisIceCreamIndy)

This site is a menu only. It does not take online orders; customers call to order.

## Structure

Everything lives in one file, `index.html` (HTML, CSS and JavaScript inline). Menu items, prices, ice cream flavors and smoothies are defined as data in the `<script>` block, with English and Spanish text side by side. To change a price or add a flavor, edit that data and commit.

## Publishing with GitHub Pages

1. Push this folder to a GitHub repository.
2. In the repo, open **Settings → Pages** and set the source to the `main` branch, root folder.
3. Once you own the domain, enter it under **Custom domain** on the same page and point the domain's DNS at GitHub Pages.

## Before launch

- Swap the camera placeholder for Instagram's official glyph (free from Instagram's brand resources).
- Double-check every price against the current in-store menu.
